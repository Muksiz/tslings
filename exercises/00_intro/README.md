# Intro

tslings is a collection of small exercises to get you used to reading and writing TypeScript.
Each exercise is a `.ts` file with a type error or a failing test. Your job is to fix it.

An exercise is checked in two steps:

1. **Type check**: `tsc` checks the file using the strict settings in `tsconfig.json`.
2. **Run**: the file is executed with Node.js. If it contains tests (`node:test`), they all have to pass.

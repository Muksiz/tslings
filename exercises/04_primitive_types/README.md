# Primitive Types

TypeScript has a handful of primitive types:

- `boolean`: `true` or `false`
- `number`: **all** numbers, integers and floating point alike (64-bit IEEE 754 floats)
- `bigint`: arbitrarily large integers, written with an `n` suffix like `123n`
- `string`: text
- `null` and `undefined`: "no value"

On top of these, TypeScript adds **tuple types** such as `[string, number]`: arrays with a
fixed length where each position has its own type.
